# Mekanism: Empowered
Mekanism を強化するアドオン Mod です。

## 追加要素

### 追加アップグレード

#### Empowered Speed Upgrade
- 機械の動作速度をさらに上昇させるアップグレード。
- 同時にエネルギー消費も増加する。
- 動作には Speed Upgrade が必要。

#### Empowered Energy Upgrade
- Empowered Speed Upgrade によるエネルギー消費増加を緩和するアップグレード。

#### Fast Item Eject Upgrade
- アイテムの排出速度をさらに上昇させるアップグレード。
- 最速で毎tickアイテムを排出する。

#### Fast Item Insert Upgrade
- アイテムの挿入速度をさらに上昇させるアップグレード。
- 最速で毎tickアイテムを搬入する。
- 動作には Auto Insert Upgrade が必要。

#### I/O Capacity Upgrade
- 機械の入出力量を増加させるアップグレード。
- Auto Insert Upgrade と併用すると搬入量も増加する。

#### Auto Insert Upgrade
- 機械にアイテムの自動搬入機能を追加するアップグレード。
